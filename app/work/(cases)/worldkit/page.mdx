## Overview

WorldKit is WorldLink's enterprise design system. It runs one pipeline — **Figma tokens → Tailwind → Storybook** — so a decision made in Figma shows up in code without anyone re-typing a hex value. It's built to WCAG 2.2.

<Callout>
  Design and code drifting apart isn't a people problem. It's a pipeline problem.
</Callout>
